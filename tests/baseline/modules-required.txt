# Modules this port must not lose. Maintained BY HAND - never regenerate it
# from a build, because the whole point is to catch a module that silently
# stopped being built.
#
# The failure this guards against: a Kconfig symbol renamed upstream is dropped
# by olddefconfig without a word, the build stays green, and the missing driver
# only shows up as a dead feature on the device. That is how the FP3 panel was
# lost once - CONFIG_DRM_PANEL_FAIRPHONE_FP3_HX83112B became
# CONFIG_DRM_PANEL_HIMAX_HX83112B, /dev/dri never appeared, and the compositor
# failed with "Found 0 GPUs" - which reads like a GPU bug, not a config rename.
#
# Names are the .ko basenames as they appear in /lib/modules, verified on the
# device rather than guessed (the charger driver, for example, is qcom_smbx and
# not the smb2 its Kconfig symbol suggests).

# display - without this there is no /dev/dri and no compositor
panel-himax-hx83112b
# touchscreen
himax_hx83112b
# camera
imx363
qcom-camss
